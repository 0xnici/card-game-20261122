Emberfall Duel — an original deck-builder card battler against the Cinder Golem. Play a hand of five from a 20-card deck, spend mana, match the golem's stance (Ember beats Thorn, Thorn beats Tide, Tide beats Ember) for bonus damage, chain same-element cards for Resonance, and break its guard before it breaks you. Keyboard and mouse, no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play.
